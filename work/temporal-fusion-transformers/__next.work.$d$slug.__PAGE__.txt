## Overview

The Mega Magic Marketplace is a dedicated digital platform designed to facilitate a safe and centralized exchange for university students. Developed by "The Squirtle Squad," the application addresses the specific constraints of campus life by providing a localized environment for buying, selling, or exchanging textbooks, furniture, clothing, and other student resources.
Developed student marketplace with user-friendly UI using Django, React and PostgreSQL, with JWT authentication.


## Technical Methodology
- **Three-Tier Architecture:** Built using a modern standard architecture consisting of a React frontend, a Django backend, and a PostgreSQL database.
- **Frontend Development:** Created an interactive interface using React (JavaScript) that handles item browsing, category filtering, and real-time search queries via REST API calls.
- **Robust Backend:** Implemented Django + Django REST Framework to manage API endpoints for user authentication, product management, and search logic.
- **Data Integrity & Testing:** Utilized Django ORM for schema maintenance and implemented seven distinct unit tests covering critical workflows like database insertion, user registration, and messaging.
- **Agile Management:** Managed development via the Scrum framework, utilizing Git feature branches and Kanban tracking to maintain a high sprint velocity.

## Technologies

- Django
- React
- PostgreSQL
- JWT Authentication
- Postman

## Key Features
- **Integrated Messaging:** Secure communication channel for users to coordinate exchanges directly within the platform.
- **Comprehensive Search:** Keyword-based searching and category filtering to enhance item discoverability.
- **Administrative Control:** Includes a Django Admin Panel for data entry, user management, and platform oversight.

## Impact & Future Scalability
- **Community Safety:** The platform mitigates risks such as transaction scams through an integrated reporting system and planned verified university email authentication.
- **Scalable Design:** The combination of PostgreSQL and Django's modular architecture ensures the system can scale to handle thousands of concurrent student users.
- **Sustainability:** Encourages a circular economy within the campus community, reducing waste by facilitating the exchange of pre-owned academic materials.
