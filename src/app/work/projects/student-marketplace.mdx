## Overview

Developed student marketplace with user-friendly UI using Django, React and PostgreSQL, with JWT authentication.

Utilized Agile project development to ensure meet project deadlines and implement features include user login, buying, selling, and reporting; utilized Postman for API testing and debugging to ensure reliability and performance.

## Technologies

- Django
- React
- PostgreSQL
- JWT Authentication
- Postman
