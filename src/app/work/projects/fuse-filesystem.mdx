## Overview

Implemented a custom user-space filesystem using FUSE in C++, supporting core file and directory operations (open, read, write, mkdir, unlink).

Modeled the filesystem hierarchy using n-ary trees and map-based data structures to efficiently manage directories, inodes, and file metadata.

Ensured POSIX-compliant behavior through correct permission handling, offset-based I/O, and robust error handling during filesystem operations.

## Technologies

- C++
- FUSE
- Data Structures (Trees, Maps)
