## Overview

Deployed scalable data pipelines use Node.js, MongoDB, and RESTful APIs, streamlining data transfer processes and reducing latency; utilized Postman for API testing and debugging to ensure reliability and performance.

Built analytics dashboard for investment platform using Next.js, creating visualizations for portfolio metrics and performance tracking that enabled data-driven investment decisions.

- Node.js
- MongoDB
- RESTful APIs
- Next.js
- Postman
